# Comparator Threshold Worst Case Model

Model ID: `comparator_threshold`

The model calculates a comparator threshold generated by a resistor divider:

```text
Vthreshold = Vref * Rbottom / (Rtop + Rbottom)
```

Worst minimum threshold uses `Vref_min`, `Rtop_max`, `Rbottom_min`, and subtracts comparator input offset.
Worst maximum threshold uses `Vref_max`, `Rtop_min`, `Rbottom_max`, and adds comparator input offset.

Limitations:

- Does not model dynamic propagation delay.
- Does not model input bias current.
- Does not model hysteresis networks beyond a static threshold.
